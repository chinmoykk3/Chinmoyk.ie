## Design Systems & Technical Rigor

- **True Neutral Dark Mode**: The dark mode palette is mathematically pure neutral (`#000000`, `#0A0A0A`, `#141414`, `#1C1C1C`), strictly guaranteeing that no neutral tone has a blue channel higher than its red or green channels ($R = G = B$).
- **Zero Inline Hex Values**: Every UI element references Tailwind semantic theme tokens (`bg-theme-bg`, `text-theme-text`, `text-chapter-accent`, `bg-chapter-wash`).
- **Resilient Fallbacks**:
  - **No-JS**: Complete progressive enhancement via `<html className="no-js">`—unpins scenes, removes overlays, and presents full readable static content.
  - **No-WebGL**: Automatic runtime detection falling back to high-fidelity SVG vector constellations.
  - **Reduced Motion**: Full OS `prefers-reduced-motion` detection and user toggle, replacing pinned scrubs with clean static fades.
- **Accessibility**: 100/100 WCAG AA compliance with visible token-based focus rings, screen-reader narrative cohesion (no `aria-live` scroll spam), and full keyboard navigation.

- **Language**: Strict [TypeScript](https://www.typescriptlang.org/)
